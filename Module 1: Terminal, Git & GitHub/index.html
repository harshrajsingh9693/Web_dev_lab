P1: Project Folder and Terminal Navigation

This is the first task in the lab. The goal is to create a project folder and practice command-line navigation.

Commands

mkdir Web_dev_lab
cd Web_dev_lab
pwd
ls
mkdir project
cd project
ls -la

What it does

  • mkdir creates a new folder.
  • cd changes the current folder.
  • pwd shows the current path.
  • ls lists files and folders.
  • ls -la shows hidden files too.
