# P1: Project folder and terminal navigation

This is the first lab task.

## Objective
Create a project folder and practice basic terminal commands.

## Commands to run

```bash
mkdir Web_dev_lab
cd Web_dev_lab
pwd
ls
mkdir project
cd project
ls -la
```

## What each command does

- `mkdir Web_dev_lab` creates the project folder.
- `cd Web_dev_lab` enters the folder.
- `pwd` shows the current location.
- `ls` lists contents.
- `mkdir project` creates another folder inside.
- `ls -la` shows hidden files as well.

## Result
The project folder is ready for future HTML and CSS work.
