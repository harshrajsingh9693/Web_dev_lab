# Web_dev_lab

A clean and organized portfolio of my web development practice work.

This repository contains my HTML and CSS learning exercises from the Programming for Web Development – I course. It tracks my progress from basic Git workflow and repository setup to responsive web layouts and polished front-end design.

## Repository structure

- Module 1: Terminal, Git & GitHub
  - Git and GitHub workflow basics, repository setup, branching, and version control practice.
- Module 2: HTML & CSS foundations
  - P5 to P13 exercises covering semantic HTML, portfolio pages, sticky navbars, flexbox, CSS Grid, landing pages, and contact sections.

## Highlights

- Clean HTML structure and semantic layout practices
- Responsive design exercises using Flexbox and CSS Grid
- Portfolio-style landing pages and project cards
- GitHub workflow practice with commits, branches, and README updates
